\# Art \& Craft Marketplace



Art \& Craft Marketplace is a full-stack web application where users can view and add art and craft products.



\## Technologies



\- React

\- Java

\- Spring Boot

\- MySQL



\## Project Structure



\- `java-spring-boot-back-end-app` - Spring Boot backend

\- `react-front-end-app` - React frontend



\## Features



\- Add products

\- View products

\- Edit products

\- Delete products

\- Add product descriptions and images

\- Review products
